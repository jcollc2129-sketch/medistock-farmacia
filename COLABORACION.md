# Como colaborar en MediStock

## Repo
https://github.com/jcollc2129-sketch/medistock-farmacia

## App en vivo
https://medistock-f1a.pages.dev/

## Para tu companero
1. Pide acceso al repo (Settings > Collaborators) o haz el repo publico.
2. Clona: `git clone https://github.com/jcollc2129-sketch/medistock-farmacia.git`
3. Abre un chat con Grok y dile: "Trabajo en https://github.com/jcollc2129-sketch/medistock-farmacia y la demo https://medistock-f1a.pages.dev/"
4. Propone mejoras; sube cambios con git push.

## Archivos principales de la app
- `index.html`, `app.js`, `db.js`, `styles.css`, `sync.js`, `sw.js`
- Si faltan en el repo, subelos desde el ZIP de la carpeta medistock (Upload files en GitHub).

## Cloudflare Pages
Conectar este repo a Cloudflare Pages para redesplegar al hacer push a main.
